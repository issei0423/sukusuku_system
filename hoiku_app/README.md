# すくすくハイブ ローカル版（Flask + SQLite）

保育支援システムのモックアップを、ローカルPCで動く形にしたものです。
データはすべて `hoiku.db`（SQLite）に保存されるので、再起動しても消えません。

## 必要なもの
- Python 3.10 以上
- pip

## セットアップ & 起動（Windows PowerShell）

```powershell
cd hoiku_app
pip install -r requirements.txt
python app.py
```

起動したらブラウザで → **http://localhost:5000**

初回起動時に `hoiku.db` が自動作成され、デモデータが入ります。

## デモアカウント（パスワードはIDと同じ）

| ID     | 役割              | できること |
|--------|-------------------|-----------|
| encho  | 管理者（園長）    | 日誌の承認・差し戻し、園チャット投稿、監査ログ閲覧 |
| shunin | 管理者（主任）    | 同上 |
| tanaka | 保育士            | 午睡チェック、発達チェック入力、組・職員・個人チャット |
| sato   | 保護者            | 個人チャット送受信、組・園チャット閲覧、承認済み日誌閲覧 |

新規登録タブから保護者アカウントも作れます（招待コード: `HIVE-2026`）。

## タブレット・スマホから使う（LAN内）

KDSのときと同じ要領です。

1. PC側で `ipconfig` を実行して IPv4 アドレスを確認（例: 192.168.1.10）
2. 同じWi-Fiにつないだ端末のブラウザで `http://192.168.1.10:5000` を開く
3. Windowsファイアウォールの許可ダイアログが出たら「アクセスを許可」

→ 保育士はPC、保護者はスマホでログインすれば、**個人チャットのやり取りや午睡状態の更新がリアルタイム（4秒ポーリング）で同期**されます。

## ファイル構成

```
hoiku_app/
├── app.py             # Flaskサーバ + SQLite（API・認証・権限すべてここ）
├── static/
│   └── index.html     # 画面（fetchでAPIを呼ぶ）
├── requirements.txt
├── README.md
└── hoiku.db           # 初回起動時に自動生成されるデータベース
```

## データベースについて

- **リセットしたいとき**: サーバを止めて `hoiku.db` を削除 → 再起動でデモデータが再投入されます
- **中身を見たいとき**: `sqlite3 hoiku.db` や VSCode の SQLite 拡張で開けます
- 主なテーブル: `users` / `children` / `naps` / `nap_logs`（監査用操作ログ）/ `channels` / `messages` / `nisshi` / `dev_results` / `dev_notes`

## 実装済みの機能

- ログイン・ログアウト・「ログイン状態を保持」（セッション14日）
- 保護者の新規登録（招待コード方式）
- 役割別の権限制御はすべて**サーバ側で**チェック（画面を偽装してもAPIが403を返す）
- 午睡チェック: 睡眠⇄起床トグル・メモ → DB保存＋操作ログ記録
- チャット: チャンネル別権限（投稿/閲覧/非表示）、送信、他端末の更新をポーリング反映
- 日誌: 承認・差し戻し（管理者のみ）、保護者は承認済みのみ閲覧
- 発達チェック: 段階入力と所見をDBに保存

## 注意（本番運用する場合）

これは学習・プロトタイプ用の構成です。実運用するなら最低限:
- `app.secret_key` を環境変数化
- Flask開発サーバではなく waitress / gunicorn 等のWSGIサーバを使う
- HTTPS化、CSRF対策、パスワードポリシー
（パスワードは werkzeug でハッシュ化済みなので平文保存はしていません）
