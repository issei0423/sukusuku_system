## 1. どのシートを直すか

本ファイルには3シートあるが、実データが入っているのは「サンプル」シートのみ。

| シート名 | 状態 | 中間発表セクションの扱い |
| :-- | :-- | :-- |
| プレゼンスケジュール | 雛形のまま（作業内容も担当者も空、進捗率すべて 0%） | 触らない |
| ガントチャート | 雛形のまま（作業内容はあるが担当者・日付すべて空） | 触らない |
| **サンプル** | **実運用シート**（メンバー名・2026年の実日付が入っている） | **ここを直す** |

シート名が「サンプル」なのは実態と合っていないが、**本指示では改名しない**。改名はシート参照を持つ数式を壊す可能性があり、チームの合意事項でもないため。

## 2. 差分（サンプルシート「中間発表」セクション）

セル番地ではなく**セクション名と作業内容名**で位置を示す（`claude.md`「章節番号ではなく項目名で参照すること」に従う）。列は左から
No.／作業内容／責任者／担当者／ファイル名／開始日／完了予定日／進捗率／備考。

### 適用する差分

| 作業内容 | 列 | 現在の値 | 変更後の値 |
| :-- | :-- | :-- | :-- |
| 中間発表本番 | 開始日 | `11/21/2026` | **`2026/11/25`** |
| 中間発表本番 | 完了予定日 | （空欄） | **`2026/11/25`** |
| 中間発表本番 | 備考 | （空欄） | **`会場：なはーと`** |

あわせて、ガントバー（日付列の色付け）を **11/21 から 11/25 へ移動**する。

### 補足

- 2026/11/25 は**水曜日**であり、連絡内容の「水曜」と一致する。
- 変更前の 2026/11/21 は**土曜日**。学校行事の日付としては不自然であり、仮置きのまま更新されていなかったものと判断した。
- 日付の書式が既存シート内で混在している（`11/21/2026` の米国式と `2026/06/15` の年月日式）。本指示では**年月日式に寄せる**が、シート全体の統一は別途チームで判断する。
