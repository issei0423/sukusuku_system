### No.01 の対応経緯（棚卸し：2026/08/27）

本指摘は3点の欠落を挙げていた。対応は2段階に分かれる。

| 指摘 | 対応 | 対応した版 |
| :-- | :-- | :-- |
| ①トップページという画面・概念自体の不在 | 「ログイン画面がトップページを兼ねる」と規定して一度解消。その後、**保護者用と職員用の2系統の入口（トップ）を持つ**方式へ改めた（「アプリのログイン」(4-1-1)「入口の2系統」） | 第1.4版 → 第2.0版で再定義 |
| ②ログイン／ログアウトとトップページの関係が未定義 | 遷移先は第1.4版で「ログアウト後はログイン画面へ戻る」と規定。第2.0版で**ログアウトを独立した要件として定義**し、遷移先（ログインしていた系統のトップへ戻る）・セッション無効化・入力途中の扱い・操作ログの扱いを明記した（「アプリのログイン」(4-1-1)「ログアウト」）。導線の配置（職員用はヘッダ、保護者用はメニュー内）も同項に規定 | 第1.4版 → 第2.0版で拡充 |
| ③新規登録が要件定義書に一切存在しない | 「新規登録（保護者）」として機能表に追加し、実体を「保護者アカウントの自己登録」(4-1-2) に定義。第2.0版で**保護者用の入口にのみ設ける**ことを明記した | 第1.4版 → 第2.0版で入口を限定 |

- 用語は「ログイン／ログアウト／新規登録」に統一した。本ファイル本文および過去の論点表に残る「サインイン」「サインアップ」は旧称であり、現在の「ログイン」「新規登録」を指す（「アプリのログイン」(4-1-1)「用語の統一」）。
- 図への反映も完了している。`図/ユースケース図.md` 第1.1版（入口の2系統、ログアウトのユースケース）、`図/アクティビティ図.md` 第1.1版（「ログアウト」(2-3) のフロー新設）。
- 本指摘のうち**基本設計へ引き継ぐ事項**：画面ID体系と画面体系図は、いずれも決着済みである（画面IDは `図/画面ID対応表.md`、画面体系図は `基本設計書.md`「画面体系図」(3-3)）。入口が2系統になったため、画面一覧も系統ごとに整理する必要がある。
