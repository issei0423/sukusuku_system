# デザイン見本の見た目に関するレビュー指摘

GitHub Issue #72。2026-10-05 に提示した `図/デザインアーキテクチャ案.md` の職員ダッシュボードと保護者ホームの画面見本に対し、ユーザーから「見た目がAIぽい」との指摘があった。

## 観察した点

- 均等な角丸カードの繰り返しが、未対応の仕事や記録の読み順を表していない。
- 曲線や丸い印が画面の役割と結びつかず、装飾になっている。
- 職員の実務と保護者が読む連絡・記録の具体性より、汎用的な画面構成が目立つ。

## 確認する論点

- 職員ダッシュボードの未対応と次の操作は、どの順序で示すと読みやすいか。
- 保護者ホームで、園児ごとの連絡と記録をどう区切れば取り違えを防げるか。
- 優しい黄色と「つながる線」を、どこに使うと意味が伝わるか。

本書は問題の指摘を記録する。画面の採用方針はチームで確認する。
