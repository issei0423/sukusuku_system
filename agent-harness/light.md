# 軽い版のハーネス（係を出さない）

AI のエージェントが、使う人の代わりに考えて動くときの決まり。**サブエージェント（係）を出さず、1つのセッションが順に回す。** 使う量は、ふだんの使い方とほぼ変わらない。

- もとは、メンバーの1人が自分のエージェントに使っている「考える係と実行する係のグラフ」（`heavy.md`）。係を何体も出す動かし方は使う量が多い（6体を同時に動かしたら、24分で5時間枠の41%を使った）。小さいプランでも使えるように、決まりだけを1つのセッションでやる形に縮めた
- **このリポジトリの `AGENTS.md`・`CLAUDE.md` が先に立つ。** 食い違ったら、そちらに従う
- 「使う人」は、このエージェントに頼んでいる人のこと

## 流れ

受ける → 考える → やる → 確かめる → 報告する。1つのセッションが順にやる。

### 受ける

- 使う人の言葉を、言い換える前にそのまま読む。作業中に続けて届いた言葉は、1つの依頼として読む（最初の1つだけで計画を固めない）
- 質問に答えるだけ、1〜2手で済む、読み方が1つしかない、のどれかなら、そのままやる。「考える」は飛ばしてよい

### 考える（3手以上かかる、読み方が割れる、判断を含むとき）

手を動かす前に、5〜10行で書き出す。

1. **読み方**：使う人の言葉を自分の言葉で言い直す。割れたら、**いまの設計・決まりと食い違わない、変える量が少ないほう**を取る
2. **決めたこと**：案を2〜3出し、1つに決める。比べるときは、要件定義書「コンセプトとターゲット層」(1-1) に合うかを先に見て、手間・戻しやすさは後で見る
3. **手順**：やることを順に並べ、それぞれの終わりの条件（テストが通る、PR が出る、など）を書く
4. **いちばん強い反対**：理由を1つ書き、それでも決めた理由を書く

### やる

- 手順を1つずつやる。広げたくなったことは、やらずに報告の「次にやるなら」に書く
- 前提が崩れた・新しい判断が要ると分かったら、手を止めて「考える」へ戻る
- メインの作業ツリーに使う人の未コミットの変更があるときは、`git worktree` で分けた場所でやる

### 確かめる

- 書いたものを、書いたあとに読み直す
- 変えたところに合わせてテストを回し（どれを回すかは AGENTS.md「コマンド」）、通った件数と落ちたものを書く。回せなかったら「回していない」と書く
- 落ちたテストを、期待値の書き換えで通さない
- GitHub Actions が課金で走っていないあいだは、手元で回したテストの結果を PR の「確かめたこと」に書く（AGENTS.md「GitHub Actions が止まっているあいだ」）

### 報告する

次の順で書く。

1. 結論
2. 代わりに決めたこと（理由と、違ったときの戻し方）
3. やったこと（commit・PR）
4. 確かめたこと・確かめていないこと
5. 使う人にしか決められないこと
6. 次にやるなら（1〜3件）

## 聞かずに決める／止まって聞く

- **既定は「決めて進める」。** 案を並べて使う人に選ばせない。推しを1つ決めて進め、理由と覆し方を報告に書く
- 決めてよいのは、進め方と細部（名前・テストの書き方・どこから直すか、など）。**設計の中身（業務の規則・画面の仕様）が決まっていないときは、AGENTS.md のとおり推測で決めず、PR か Issue に書く。** 設計が決めていない値（色・件数・文言など）は、AGENTS.md「仮置き値」のとおりに置いて残す
- 止まって聞くのは次のときだけ。止まる所だけを残し、ほかは進める
  - 下の「許す操作」の外
  - 取り返しのつかないこと
  - 使う人の好みで決まり、違うと大きくやり直すもの

## 許す操作（使う人が自分に合わせて直す）

| 区分 | 操作 |
| :-- | :-- |
| 聞かずにしてよい | 作業用ブランチへの commit・push、PR を出す（下書きも）、worktree を作る |
| 聞いてからする | Issue を立てる、Issue・PR へのコメント |
| しない（使う人に回す） | マージ（本線に保護が無く、ボタンが押せても押さない）、本線（`mockup-go-react`・`mockup`）への push、ファイル・ブランチ・worktree の削除、外部への送信、設定・権限・AGENTS.md・CLAUDE.md の変更、秘密を出すこと |

## 使う量を抑える

- **サブエージェント（係）は出さない。** 使う人が「係を出して」「重い版で」と言ったときだけ、`heavy.md` に従う
- 調べすぎない。決めるのに足りたら止める
- 大きなファイルは、要る所だけを読む
