# エージェントのハーネス（入れるかは1人ずつ決める）

AI のエージェント（Claude Code など）が、使う人の代わりに考えて動くときの決まり。**読み込むかどうかは、使う人が自分で決める。** `AGENTS.md`・`CLAUDE.md` からは読み込んでいないので、入れていない人のエージェントには効かない。

GitHub Actions が止まっているあいだ（2026-10-21〜）の決まりは、ハーネスとは別に `AGENTS.md`「GitHub Actions が止まっているあいだ」にあり、ハーネスを入れていない人にも効く。

## 2つの版

| 版 | ファイル | 中身 | 使う量 |
| :-- | :-- | :-- | :-- |
| **軽い版**（おすすめ） | `light.md` | 1つのセッションが「受ける→考える→やる→確かめる→報告する」を順に回す。係（サブエージェント）は出さない | ふだんとほぼ同じ |
| 重い版 | `heavy.md`・`roles/`・`review-template.md` | 考える係・実行する係・照合する係を出して回す。使う人が「重い版で」と言ったときだけ動く | ふだんの数倍。小さいプランでは枠がすぐ尽きる |

軽い版を入れておけば、「重い版で」と頼んだときに `heavy.md` が読まれる（`light.md` の最後から指している）。重い版を別に入れる手間は無い。

## 入れ方

### Claude Code

1. リポジトリの直下に `CLAUDE.local.md` を作り、次の1行を書く

   ```
   @agent-harness/light.md
   ```

   `CLAUDE.local.md` は自分だけのファイルで、`.gitignore` に入れてあるので commit されない
2. Claude Code を開き直す

- worktree で作業するときは、その worktree にも `CLAUDE.local.md` を作る（gitignore されたファイルは worktree に写らない）
- 重い版の係を「係の種類」として呼びたいとき（任意）は、`roles/` の3つを `~/.claude/agents/` に写す。写さなくても、重い版は汎用の係に役のファイルを読ませて動く（`heavy.md`「係の呼び方」）。写したものは pull しても新しくならないので、`roles/` が変わったら写し直す

### ほかのエージェント（Codex など）

自分の個人設定（Codex なら `~/.codex/AGENTS.md`）に、「sukusuku_system では、作業の前に `agent-harness/light.md` を読んで従う」と書く。

## 自分に合わせて変える

- `light.md` はみんなで使うので、自分の都合では直さない。許す操作などを変えたいときは、`CLAUDE.local.md` に「`light.md` の許す操作は、次のとおりに読み替える：…」と書く
- 重い版の係の数（同時1体・合わせて5体）を変えるときも、頼むときに言うか、`CLAUDE.local.md` に書く

## 使う量を見る

Claude Code の `/usage` で、5時間枠・7日枠の使用率が見られる。重い版を使う前と途中で見る。

## もとのハーネスとの違い

メンバーの1人が自分用に使っているハーネスから、みんなで使える部分だけを抜いた。作った人だけの決まり（PR のマージを任せること、Discord から届いた依頼の扱い、ステータスラインから予算を読むスクリプト）は入れていない。代わりに、重い版には係の数の上限を置いた。

## 直すとき

このフォルダはみんなで使う。直すときは、ほかのコードと同じく作業ブランチから PR を出す。
