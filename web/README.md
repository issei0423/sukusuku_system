# web — すくすくシステム モックアップ（React + TypeScript）

基本設計書 第1.3版の全33画面。動かし方・デモアカウント・構成は、リポジトリ直下の
[`MOCKUP.md`](../MOCKUP.md) を参照。

- `npm run dev` … 開発サーバ
- `npm test` … テスト87件
- `npm run build` … 本番ビルド

設計で確定していない値をどこにどう置いたかは [`仮置き値.md`](仮置き値.md) にまとめている。

なお `public/` と `src/assets/` に残っている画像は Vite の雛形が置いたもので、
本アプリからは参照していない。
