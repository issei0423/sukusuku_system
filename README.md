# すくすくシステム（すくすくハイブ）

保育支援システム。保護者という「点」と保育士という「点」を、育児という「線」でつなぐ、園児管理を兼ねたコミュニケーションツール。
チーム開発演習（Hive-Five Developers）の成果物。

> 補足: 以下の背景・設計原則は `claude.md` および `要件定義書.md` を参照して記載しています。

## 背景・コンセプト

| 項目 | 内容 |
| --- | --- |
| テーマカラー | 優しい黄色 |
| コンセプト | 保護者という点と保育士という点を、育児という線でつなぐ園児管理を兼ねたコミュニケーションツール |
| ターゲット層 | 保育士と保護者 |

- 保護者の要望: 子供の状態・行動がいち早く／どこでもわかる、シンプルで直感的なUI/UX
- 保育士の要望: 資料管理の負担軽減、日誌などの書き込み効率化

開発のねらいは、チャット・日誌機能による情報共有の迅速化と、「保育日誌システム」構築による事務作業時間の削減を通じて、保育士が子供と向き合う時間を最大化すること。

### スコープ

- 対象: 日誌の作成・編集・承認フロー／園児情報の簡易管理／過去日誌の検索・閲覧／職員・保護者間チャット／午睡（昼寝）中の安全管理と記録支援／0〜5歳児の発達状況の記録・蓄積・比較
- 対象外: 法定健診（乳幼児健診）の代替、医療的診断・発達障害の判定・療育要否の判断、保護者向け閲覧画面・お知らせ配信（保護者ポータル側の責務とする）

## 設計原則

基本設計書（UI設計方針）より:

- **認知負荷の低減**: 説明書なしで直感的に操作できること。タイマーなど重要情報は常に視認可能な位置に固定する。
- **デバイス別レイアウト**: 保育士・管理者（PC/タブレット）は情報を俯瞰できる12カラムグリッド、保護者（スマートフォン）は片手操作前提のシングルカラム。
- **配色ルール**: ベースカラーは「優しい黄色」。SIDS関連アラート等の重要通知には補色の「警告赤」を使用し視認性を確保する。
- **権限モデル**: 管理者（園長・主任）／一般（保育士）／保護者の3ロールで、利用者種別により表示・操作を切り替える。権限チェックは画面側でなく**サーバー側**で行う（実装済みモックアップで確認済み）。
- **記録と判定の分離**: 発達チェック等は「記録・観察支援」に責務を限定し、医療的な判定・診断は行わない。

## 機能一覧

1. **日誌システム** — 下書き・作成 → 承認申請 → 承認/差し戻し → 保管・共有（テンプレート選択、定型文、写真添付、ステータス管理、検索、PDF出力）
2. **チャットツール** — 職員チャット／グループチャット／個人チャット／園チャット（ロールごとに送受信・閲覧のみを制御）
3. **午睡チェック** — 年齢別間隔でのタイマー通知、体位記録、操作ログ、監査用帳票出力、一括確認画面
4. **発達チェック** — 月齢別チェックリスト、推奨スケジュール提示と手動上書き、身体測定・成長グラフ、保護者ポータルへのデータ連携

## 技術スタック

本プロジェクトで採用する構成:

- **バックエンド**: [Go](https://go.dev/)
- **DB**: SQLite3。初回起動時に `hoiku.db` を自動作成しデモデータを投入
- **認証/セキュリティ**: サーバー側セッションによるログイン状態の保持、パスワードのハッシュ化
- **フロントエンド**: [TypeScript](https://www.typescriptlang.org/) & [React](https://react.dev/)
- **フォント**: Google Fonts（Zen Maru Gothic, Noto Sans JP）をCDN経由で読み込み
- **依存管理**: バックエンドは `go.mod`、フロントエンドは `package.json`

> **注意**: `mockup` ブランチの `hoiku_app/` にある既存のモックアップ実装は、Python / Flask と素の HTML・CSS・JavaScript で作られており、**上記の構成へはまだ移行していません**。以下の「主なAPIエンドポイント」「ディレクトリ構成」「セットアップ」は、移行前のモックアップ実装についての説明です。

### 主なAPIエンドポイント（`app.py`）

`/api/login`, `/api/signup`, `/api/logout`, `/api/me`, `/api/bootstrap`, `/api/nap/<id>/toggle`, `/api/nap/<id>/memo`, `/api/nap_logs`, `/api/channels/<id>/messages`, `/api/nisshi/<id>/status`, `/api/dev/<id>`

### 主なDBテーブル

`users` / `children` / `naps` / `nap_logs`（監査ログ）/ `channels` / `messages` / `nisshi`（日誌）/ `dev_items` / `dev_results` / `dev_notes`

## ディレクトリ構成

このリポジトリは目的別にブランチが分かれており、実装コードは `mockup` ブランチにあります。

```
sukusuku_system/
└── hoiku_app/              # 保育支援システムのモックアップ実装（mockupブランチ）
    ├── app.py               # Flaskサーバー（API・認証・権限・DBスキーマ）
    ├── static/
    │   └── index.html       # フロントエンド画面一式（ログイン〜各機能画面）
    ├── requirements.txt     # 依存パッケージ（flask）
    ├── README.md            # hoiku_app のセットアップ手順
    └── hoiku.db             # 初回起動時に自動生成されるDB（リポジトリには含まれない）
```

### ブランチ構成

| ブランチ | 内容 |
| --- | --- |
| `main` | ベースブランチ |
| `docs` | ドキュメント（本README等） |
| `mockup` | 動作するモックアップ実装（`hoiku_app/`） |
| `テンプレート` | 学校配布のテンプレート |

## セットアップ（`mockup` ブランチの `hoiku_app/`）

```powershell
git checkout mockup
cd hoiku_app
pip install -r requirements.txt
python app.py
```

起動後、ブラウザで `http://localhost:5000` にアクセス。
