## 2026-10-17 ｜ 競合の保育ICTの、保護者向けの機能

**調べた理由**：`設計方針.md` で「競合が強いところ」と「このシステムが勝ちに行くところ」を分けるため。持ち主が「保育士の仕事効率化や一元管理などは他に競合他社がいる」と述べ、インタビュー（`20260609議事録まとめ.md`）でもコドモンが「業界シェアNo.1」「子供の成長記録など伸びしろがある分野は手薄」と語られた。Web 検索は10回までと決めて行った（下の2項も含む）。

**分かったこと**：

- **コドモン**（App Store の説明）：保護者アプリで、施設からの緊急連絡・おたより・アンケートの受信、日々の連絡帳の提出、欠席・遅刻・延長保育の申請ができる。施設で撮った写真の閲覧と購入、行事のカレンダー、登降園時刻・請求・身長体重などの成長記録の確認、連絡帳の製本ができる。施設の使い方によって使えない機能がある。2026年3月から、連絡帳に添付した写真を月ごとに配信し、施設が許せば保護者が購入できる「連絡帳写真アルバム」が始まったと報じられた
- **コドモンの文章の AI**：校正・翻訳に対応した「文章お助けAI（ベータ版）」を、保育ICTを使う施設向けに無料で提供すると発表した（2026年1月から、対象100施設）
- **ルクミー（ユニファ）**：保護者アプリ「ルクミー for FAMILY」で、写真つきの連絡帳、個別チャット、おたよりの閲覧、登降園の打刻ができる。園の側には、センサーで体の向きを自動で記録し、うつぶせや動きが止まった状態が続くと知らせる「ルクミー午睡チェック」がある
- **はいチーズ!システム**：午睡センサー（icuco touch&care）の情報を自動で取り込む連携を発表した
- **べビモニ**：カメラの画像で体の向きを判定して午睡の記録を作る。コドモンと連携すると保護者も午睡時間を見られる、と事業者の資料にある
- **キッズリー**：写真の投稿、連絡帳、入園からの成長の記録の保存（2016年ごろの発表）
- **hugmo**：連絡帳（hugnote）、マット型センサーによる午睡の見守り、自治体へ出す形式での午睡チェックの出力（2018〜2019年ごろの記事）
- 自治体の保育ICTの機能要件の例（北本市）に、保護者アプリで連絡帳などを項目別に一覧で見せることが挙がっている
- まとめ：競合の強みは、登降園・請求・書類・写真販売・午睡センサーといった**園の事務と設備の一元化**にある。保護者向けにも連絡帳・おたより・チャット・写真はそろっている

## 2026-10-17 ｜ 外部の生成AIへ個人情報を入れるときの注意と、Claude の API の扱い

**調べた理由**：`設計方針.md` で、保護者へ送る文の下書きに Claude Haiku を使うにあたり、園児の記録を外部の API へ送ることの守りを決めるため。

**分かったこと**：

- 個人情報保護委員会は 2023年6月2日に、生成AIサービスの利用に関する注意喚起を出した。個人情報取扱事業者がプロンプトに個人情報を入れるときは、特定した利用目的を達するのに必要な範囲かを十分に確かめること。本人の同意なく個人データを入れ、それが応答の出力以外に使われると法に反するおそれがあるため、**提供者がそのデータを機械学習に使わないことなどを十分に確かめる**こと、とされる
- Anthropic の API について、二次情報（解説記事）は「商用の規約で、顧客の入力を学習に使わない」でそろっている
- 保持期間は、二次情報で「30日以内に消す」「2025年9月から7日に短くした」などと食い違う。対象の企業には、保持しない契約（ZDR）があるとされる
- Claude Haiku 5.5（`claude-haiku-5-5`）の料金は、入力100万トークンあたり0.10ドル・出力0.50ドル（プロンプトが10万トークン以下のとき。超えると0.50ドル／2.50ドル）。temperature などは既定から変えられず、拒否のときに別のモデルへ回すサーバ側の仕組みは無い

**出典**：

- 注意喚起の報道（2023-06-13）：https://scan.netsecurity.ne.jp/article/2023/06/13/49506.html
- 内閣府の会議資料：https://www8.cao.go.jp/cstp/ai/ai_senryaku/3kai/kojinjouhou.pdf
- Anthropic のデータの扱い（二次情報）：https://www.getvoibe.com/resources/claude-api-data-retention/ 、https://char.com/blog/anthropic-data-retention-policy
- Haiku 5.5 の料金と仕様：Claude Code に同梱の Claude API の参照資料（2026-10-06 時点のもの。URL ではない）

**未確認**：

- 注意喚起の本文（個人情報保護委員会のページ）は開いていない。報道と資料の要約による
- **Anthropic の商用の規約・データ処理の取り決め（一次資料）は見ていない。** 学習に使わないこと、保持期間は、導入の前に一次資料で確かめる
- 外部の AI へ送ることを、個人情報保護法の「委託」として扱えるか（法務の確認。本システムは実際の園へ導入しないため行わない）
- 料金は参照資料の値で、Anthropic の料金ページでは確かめていない

## 2026-10-17 ｜ iPhone で Web Push を受け取る条件

**調べた理由**：`設計方針.md` で、保護者がアプリを開いていないときに緊急でない新着を知らせる手段として、Web Push（PWA）を使えるか確かめるため。保護者の端末の多くはスマートフォンである。

**分かったこと**：

- iOS / iPadOS 16.4 以降で、ホーム画面に追加した Web アプリ（PWA）に Web Push を送れる
- Safari では、**ホーム画面に追加していないサイトは通知の許可を求められない**。Web アプリのマニフェスト、Service Worker、Push API・Notifications API が要る
- 許可を求める前に、利用者が何かを押す操作が要る
- iOS 16.4 では、Safari 以外のブラウザからもホーム画面に追加できるようになった

**出典**：

- CodeZine の記事：https://codezine.jp/news/detail/17600
- MoEngage の開発者向け資料：https://www.moengage.com/docs/ja/developer-guide/web-sdk/web-push/safari-web-push-for-i-os-and-i-pad-os.md

**未確認**：

- Apple（WebKit）の公式の記事は開いていない
- 通知がどのくらい確実に届くか（端末の省電力の設定、集中モードなど）。Web Push は届かないことがある補助として扱う
