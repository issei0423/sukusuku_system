# ナレッジ

保育士業務効率化Webアプリ プロジェクトの、再利用可能な知識の置き場。

## `進捗ログ.md` との使い分け

| | 何を書くか | 並び |
|---|---|---|
| `進捗ログ.md`（リポジトリ直下） | **いつ何をやったか**の作業履歴 | 新しい順・追記式 |
| `ナレッジ/`（ここ） | **何が分かっているか**の再利用可能な知識 | テーマ別 |

同じ内容を両方に書かない。作業の事実は進捗ログ、そこから得られた知見はナレッジへ。

## ファイル一覧

- [決定事項.md](決定事項.md) — 設計判断と、そう決めた理由
- [調査メモ.md](調査メモ.md) — 保育業務・法令・他社事例などの調べもの
- [用語集.md](用語集.md) — 機能名・業務用語の定義統一
- [実機で確かめる.md](実機で確かめる.md) — iPad の画面をパソコンに映す手順（テザリング・ホットスポット・ミラーリング）
- [Discordログ/](Discordログ/) — Discord経由のやりとりの記録

## 記録の原則

- 日付は絶対日付（YYYY-MM-DD）。「今日」「先週」などの相対表現を使わない
- 機能は番号ではなく機能名で書く（発達チェック／保護者ポータル／午睡チェック など）
- 確定した事実と、検討中の案を混ぜない。検討中は「検討中」と明記する
