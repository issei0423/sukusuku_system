# Discordログ

Discord経由でのやりとりの記録。

## ファイルの分け方

日付ごとに `YYYY-MM-DD.md` を作る。1日のうちに複数の話題があれば見出しで分ける。

## 書式

    ## HH:MM ｜ 話題（1行）
    **発言者**：表示名
    **内容**：発言の要旨
    **対応**：Claudeが何を答えたか／何をしたか

## 記録の原則

- **ユーザーIDは書かない**。表示名のみを記録する
- 個人情報（園児名・保護者名・連絡先など）が流れてきた場合は記録しない
- 決定事項に昇格したものは `../決定事項.md` に転記し、ここには「決定事項へ転記」とだけ残す

## 注意

このディレクトリの内容はgitの履歴に残る。Discordの発言をそのまま保存する運用のため、書き込み後の削除では履歴からは消えない。
