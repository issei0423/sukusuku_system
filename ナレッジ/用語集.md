# 用語集

機能名・業務用語の定義を統一するための一覧。表記ゆれを防ぐ目的。

## 機能名

機能は**番号ではなく機能名（固有名）で呼ぶ**。成果物で `F-15` `N-15` のような番号を新たに振らない。

| 機能名 | 説明 | 旧番号（読む時の対応表） |
|---|---|---|
| 発達チェック | 園児の発達状況の記録・可視化。身体測定を統合済み | F-15 |
| 身体測定 | 身長・体重等の測定記録。**発達チェックに統合済み**で独立機能ではない | F-16 |
| 保護者ポータル | 保護者向けの閲覧画面。発達チェックとはデータ連携のみ | F-17 |
| 日誌システム | 保育日誌の作成・管理 | — |
| チャットツール | 職員間の連絡 | — |
| 午睡チェック | 午睡中の呼吸・体位の記録 | — |
| 登降園管理 | 園児の登園・降園の記録 | — |
| 保育記録 | 日々の保育の記録 | — |

旧番号が残っている文書を改訂する際は、機能名表記に置き換える。

## 業務用語

| 用語 | 定義 |
|---|---|
| 園 | 保育所・認定こども園などの施設。システムの契約単位 |
| マスタデータ | 園が設定変更できる基準値。チェック頻度・しきい値など。ハードコードしない |
| 手動上書き | 園児単位でマスタの設定を個別に上書きする操作。必ず考慮する |

## 表記ルール

- 「保育士」と「職員」：資格を要する文脈は保育士、園の従業員一般は職員
- 「園児」と「子ども」：システム上のレコード対象は園児、一般的な記述は子ども
- 日付は YYYY-MM-DD（相対表現を使わない）
