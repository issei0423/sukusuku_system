# 用語集

機能名・業務用語の定義を統一するための一覧。表記ゆれを防ぐ目的。

## 機能名

機能は**番号ではなく機能名（固有名）で呼ぶ**。成果物で `F-15` `N-15` のような番号を新たに振らない。

| 機能名 | 説明 | 旧番号（読む時の対応表） |
|---|---|---|
| 連絡帳 | **中心の機能**（2026-10-17 に `設計方針.md` で新設を決めた）。園児ごと・日ごとの1ページで、「家庭から」（朝）・「きょうのようす」・「園から」（夕方）の3つの欄を持つ。記録した時点で保護者に届く | — |
| 日誌システム | 保育日誌（クラス日誌・個人日誌・週案月案・ヒヤリハット）の作成・申請・承認。**園内の記録**で、保護者へは届けない。例外は、保育士が申請するときに「保護者へ共有する」を選び、管理者が承認した個人日誌だけ（保護者は「園からの日誌」で読む。2026-10-29） | — |
| チャットツール | 園と家庭の会話の窓口と、職員間の連絡。園チャット・クラスグループ・目的別グループ・個人チャット・職員チャットと、園からの配布物を持つ。記録はチャットに流さない | — |
| 午睡チェック | 午睡中の体位・呼吸・顔色・体温の確認の記録（監査の層）と、「ねた・おきた」（伝える層。連絡帳で保護者に届く） | — |
| 発達チェック | 園児の発達状況の記録・可視化。身体測定を統合済み。保護者向けの「成長の記録」もこの機能に属する | F-15 |
| 身体測定 | 身長・体重等の測定記録。**発達チェックに統合済み**で独立機能ではない | F-16 |
| 保護者ポータル | **廃止済み**（2026-07-28）。保護者の入口は保護者ホームの1つで、会話はチャット、記録は連絡帳と成長の記録で読む | F-17 |
| 登降園管理 | 園児の登園・降園の記録。**対象範囲外**（要件定義書「対象範囲」(2-2)。今後の検討対象）。欠席・遅刻は連絡帳の「家庭から」か個人チャットで受ける | — |
| 保育記録 | 2026-07 の初期の提案（`システム提案.md`）での呼び名。いまは連絡帳・午睡チェック・発達チェックに分かれている | — |

旧番号が残っている文書を改訂する際は、機能名表記に置き換える。

## 業務用語

| 用語 | 定義 |
|---|---|
| 園 | 保育所・認定こども園などの施設。システムの契約単位 |
| マスタデータ | 園が設定変更できる基準値。チェック頻度・しきい値など。ハードコードしない |
| 手動上書き | 園児単位でマスタの設定を個別に上書きする操作。必ず考慮する |
| きょうのようす | 連絡帳の真ん中の欄。午睡（ねた・おきた）・食事・排せつ・体温・活動・写真が、記録した時点で時刻つきで並び、保護者に届く（`設計方針.md`） |
| 伝える層／監査の層 | 同じ出来事について、保護者に伝える記録（例：ねた・おきた・何分）と、園が安全と監査のために残す記録（例：5分ごとの午睡チェック）を分けて持つ、その2つ。監査の層は保護者に見せない（`設計方針.md`） |
| 関所 | 記録が保護者に届く前に通る確かめ。そのまま届く／送る人が確かめて届く／園内に留める／電話で伝える、の4つの段に分ける（`設計方針.md`） |
| 成長の記録 | 保護者向けの画面の名前。身長・体重のグラフと、発達チェックの「確認できた」項目（できたこと）を見せる。機能としては発達チェックに属する（`設計方針.md`） |
| 保護者ホーム | 保護者の入口の画面。園児ごとの「きょう」の区画（その日の連絡帳の要約・未読・入口）を先頭に置く |
| 本線 | ブランチ `mockup-go-react`。Go + React の Web アプリがあり、GitHub の既定のブランチ。直接 push しない |
| 公開先（本番） | 本線を自動で反映している、Oracle Cloud（OCI）の VM の Web アプリ。**アプリの正はここ**で、`localhost` で立てて使う・運用する方式は無い（2026-11-06）。URL は本線の `deploy/oci-free/README.md` だけが持つ。デモ専用で実データを入れない |
| 旧 Flask 版 | 2026-09-07 まで使った Python / Flask のモックアップ（`mockup` ブランチの `hoiku_app/`）。2026-11-06 に消した（GitHub PR #396） |

## 表記ルール

- 「保育士」と「職員」：資格を要する文脈は保育士、園の従業員一般は職員
- 「園児」と「子ども」：システム上のレコード対象は園児、一般的な記述は子ども
- 日付は YYYY-MM-DD（相対表現を使わない）
